## 五、红线与纪律速查（v2.4 形态，叠加 8-23 红线）

- **标注必挂**：`draft` 或已过期落点进正文，同页必须有依据标注——它是隐藏禁令的等价物；**漏标是纪律失效，多标只是页脚多一行**（provenance 缺席时按 calibration 回退，方向偏严）。
- **断言预算未动**：calibrated 仍是判断句背书唯一来源；未过门落点可进主旨句但语域限"我们建议"。
- **数字不由 LLM 决定**；一个占位符＝整条落点；中文数字同样算数（列举计数不算）。
- **阈值有数据再定**（裁决⑤⑨一贯口径）：任何"先设个数"的冲动先想想卡片上限 6~8 是怎么被撤回的。
- 纪律型条目禁入知识库；种子禁预置 calibrated/active；反例只收真跑样本；锁定文案禁编造正文。
- 命名禁纯序号；**判据名字与语义必须一致**——语义作废的判据走 retire，不改 message 留名。

## 追记一 · 2026-08-29（晚）· 计划项改用事项名，废除纯序号

**用户裁决**：*"我们在沟通时候，经常会出现编号，比如轨 A1 和主轨步 1，但是这个我其实完全不知道是什么，是否可以不再用编号，而是说事项的方式进行说明？"*

**判据**：这与规则 1.7「禁纯序号，语义代替数字，通过名字能推出意图」是同一条纪律——此前只执行在代码标识符上，计划项与对话却仍在造 `序列 2`／`轨 A1`／`步 3` 这类纯序号。**编号只有写的人知道指什么，读的人每次都要回表查**，这正是规则 1.7 要消灭的东西。

**新纪律（此后适用于计划、对话、提交信息、文档小标题）**：

- **计划项一律以事项名指认**，名字说的是**做完之后成立的事实**（"造价章出金额"），不是动作编号；
- **编号只在需要定位时进括号**：规范条文号（规则 4.10c）、裁决编号（裁决⑮）、release tag（`lighting@v6`）、提交号——这些是**文档地址**，保留；纯排序编号（序列 N／步 N／轨 X）**废除**；
- 顺序仍是纪律，但顺序由"先后关系"表述（"排在 X 之后"），不由编号承载。

### 二、五个实现判断（非裁决，实现选择，可推翻但要给出替代）

1. **单价投影而不是在 parameters 手写镜像**：镜像会漂移——新增一条单价忘了加，就是造价章静默少
   一项。投影是全域一致的结构规则，加一条单价＝加一行数据。
2. **id 换前缀 `attr-price-*` → `lkp-price-*`**：契约 `anchors[].lkpId` 恒 `lkp-` 前缀，而正文数字
   只能经 `{lkp-*}` 引用。二者不是同概念两套名（规则 1.8 第四条）：`attr-` 是单价库资产（全国/分档、
   带两源与时效），`lkp-` 是本户按城市档选出的那个区间——同 parameters 的"公式资产 → 代入后的落点"。
3. **落点单位派生为「元/计价单位」**：只给「㎡」会被写作器读成面积。开发规范 §4.1 量纲入名的数据侧同款。
4. **城市档取值＝数据自带的档名词面**（"一线"逐字命中 `props.breakdown` 的键），不另立 tier 枚举、
   不建映射表——映射表一旦存在就会与数据漂移；命不中取全国粗档是**正确答案不是降级**
   （细分也可能按墙体类型/档位分）。
5. **`numberClass` 挂在 entity_type 上给 `analysis`**：单价不是现场画线定位的数（重标判据），也不是
   商品参数（选型数字的定义）。attributes 表没有 number_class 列，同一 entity_type 的数字类别本就同一个。

**城市档不进写作 prompt**（第六条，归在 reportgen 侧）：档已在求值线用掉，下发只会诱出"一线城市…"
这类关于这家人的陈述。已加 prompt 回归钉住。

### 五、给下一个 session 的坑（接正文第六节）

9. **`--validate` 的影子 schema 曾少建两列**：迁移是按"文件名带 rulebook"挑的，V4 文件名里没这个词，
   于是 `examples`/`status` 一直没建、`--validate` 从 V4 起就跑不通。已改为按**迁移体内有
   `${rulebook_schema}` 占位符**挑。新增迁移时不必再讲究文件名，但**必须**用这个占位符。
10. **升判据版本要写 `version:` 在种子里**：唯一键是 `(asset_id, version)`，不写就是就地改 v1——
    等于把它在历史 release 里的样子也改了。改语义就升版本，老行留档。
11. **造价章的钱不是"总价"**：五条落点是**单价**（元/㎡、元/点位）。规则 5.15 的"分项造价 = 量 × 单价"
    里的**量**还没有——它要从定稿平面算（拆改㎡、点位数、涂刷面积、定制投影㎡），归 floorplan 那条线。
    别看到金额就以为造价章齐了。
12. **`cityTier` 是画像字段但不是可复述的话**：进包、不进 prompt。要用它做别的（比如渲染层标注
    "本地行情"）请显式取，不要顺手塞进写作素材。
