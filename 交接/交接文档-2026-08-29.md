## 一、本次裁决（全部已落《落地假设与拍板清单》§〇）

### 1. 隐藏档取消，纪律形态改为标注（规范 v2.3 → **v2.4**，§14.9）

**用户原话**：*"未校准资产禁止进入 PAID 产物，这条限制我认为应该去掉，我们的整个产品策略就是给客户建议，如果建议有问题，我们后续应该调整，而不是隐藏掉，这样对客户也没有价值，我们也没法迭代；过期的降级方式是给标记，数据来源和时间，但是还是使用这份数据。"*

**推翻的六处**：

| 原条文 | v2.4 |
|---|---|
| 规则 4.10「未校准资产禁止进入 PAID」（v1.2 立） | **作废**——照常进，随标注 |
| 规则 4.10c 三条隐藏判据（定位数字／无区间形态／判不准） | **全部作废**（昨天刚写进去） |
| 规则 4.10a「经验条目只能降档或不收录」 | 受限的是**语域**不是**存在** |
| 规则 4.18「经验判断整批降档或缺席」 | **照发并标注** |
| 规则 5.15「单价过期 → 只出占比不出金额」 | **照常出金额 + 标取数时间** |
| §12 禁止项四条 | 两条作废、两条改射程 |

**裁决逻辑（要记住，因为它推翻的是立了三个版本的条文）**：隐藏的成本一直被低估——它同时拿掉了**业主的价值**（藏起来的建议等于没有）和**系统的信号**（规则 4.17 的行为信号全部来自业主对内容的反应）。于是规则 4.10a 的转正路径在冷启动期成了**死循环**：藏起来 → 没信号 → 转不了正 → 继续藏，而冷启动期正是最需要信号的时候。真正要防的风险不是"业主看到没依据的数"，是"业主**误以为**这个数有依据"——标注解决它，成本低得多，业主还拿回了判断权。

**新纪律（替代隐藏档）**：**标注必挂**——`draft` 或已过期落点进正文的，同一页必须出现它的依据标注（来源 + 取数时间），**未标注即违规**。拦截点从"说出来"移到了"不标就说"。这是确定性判据、机检可判。

**没被推翻的两条**：
- **断言预算（规则 5.8/4.13）原样保留**——它管"以什么底气说"，不管"能不能说"。calibrated 仍是判断句背书的唯一来源，只是不再兼任"能否出现"的开关。draft 的数照出，语域限"我们建议"，不能写成"国标要求"。
- **`conflict` 仍不进 release**——标注解决不了两源互斥，标哪个都是替业主选边。

## 五、红线与纪律速查（叠加在 8-23 红线之上）

- **AI native**：无人审、无转人工、无运营编辑后台、无人预设模板。"不依赖人"只管系统**运行**不管**迭代**——人的改动走"改源 → AI 编译成数据 → 核验 → release"（规则 4.19）。
- **数字不由 LLM 决定**：落点派发前求值完，正文数字只经 `{lkp-*}` 引用。**一个占位符 = 整条落点**（区间不许拆成 `-min`/`-max`，拆开会丢掉另一端）。
- **中文数字同样算数**，列举计数不算（"四个区域"合法）。
- **命名禁纯序号**：前缀即命名空间（`art-/dom-/pt-/cr-/lkp-/gap-/prec-/gen-/stage-/tier-/acc-`）。
- **纪律型条目禁以知识条目入库**（规则 4.10b）；种子禁预置 `calibrated`、禁预置 `status=active`——拦截权只能由观察期授予。
- **禁以想象填充判官反例库**：反例只收真跑观察到的样本。**一条真样本胜过十条编的。**
- **锁定文案禁编造正文**：法律性质话术，缺一句只是少说，编一句是替企业作错误承诺。
- **v2.4 新增**：`draft` 或已过期落点进正文**必须随页标注**（未标注即违规）；标注不是可选的礼貌，它是隐藏禁令的等价物。

## 六、给下一个 session 的三个坑（都是真踩过的）

1. **"一条 `cr-` 只能属一层"是结构约束，不是风格偏好**。`verify_seeds` 写死"带 `examples` 者必须 `observing`"，而 reportgen `gate` 执行 pattern 时**不看 status**。所以规则层（恒 `active`）与判官层（`semantic_judge` + `observing`）互斥——给既有 regex 判据挂样例会让**表说假话**。**"gate 忽略 status"是正确实现，不是 bug，别顺手修。**（裁决⑥要把它升成规则 4.10d，升之前尤其别动。）

2. **过拦与漏拦同样是失效**。两次栽在这上面：`gate-chinese-numeral` 收紧后漏掉了它自己的立案样本，同时把"四个区域"误判；`AnchorPresentationPolicy` 只看顶层键，把造价章整章判没了。**改判据必须回归立案样本。**

3. **persona 判断句样例：示范句越多，过检率越低**。四轮 A/B 实证，机制是模型把 ✓ 逐字抄进卡片当结论（已加 `gate-sample-verbatim-copy`）。为保样本量试的非对称规则 **0/6，比对称规则更差**——样本量不是稀缺资源，**可抄性才是代价**。
