## 并行怎么组织（照抄即可）

- 每个 agent 一个仓一个 worktree 一个分支：`git -C <仓> worktree add ../<仓>.wt-<事项> -b <分支> main`；agent 的起始目录是中控仓的隔离 worktree，**要在提示里写清目标仓与建树命令**。
- 提示里点名同仓别人在改的文件；显式 `git add`，禁 `stash`，不 push；做完一步提交一步。
- agent 会停在"等后台任务/等网关起来"——提示里写死"等待一律用 sleep 循环，不要退出等事件"；卡了就 SendMessage 续，连卡两次就重起一个。
- 真跑用测试网关：一个 agent 一个端口，跑完只杀自己端口的两个进程。
- zsh 不按空格拆变量，循环用显式参数；pytest 在仓根起。
- 合并顺序：上游仓先合（render3d → imagegen → aipipe），同仓多分支按"改 src 的先、只加 `_iteration` 的后"。
